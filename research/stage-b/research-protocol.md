# OpenScout AI Stage B 用户任务研究协议

协议版本：v1.0  
锁定日期：2026-09-17  
研究状态：招募前；尚无参与者数据

## 1. 研究目的

验证目标用户能否在 15 分钟内使用 OpenScout 完成一次可追溯的公开 GitHub 产品研究，
并判断是否值得继续迭代推广。研究只测量任务行为，不把结果解释为市场规模、付费意愿或
商业需求的直接证明。

## 2. 目标参与者

招募 5—10 名成年人，优先覆盖以下角色：

- 研究 AI 开源产品的产品经理或产品运营人员；
- 跟踪竞品变化的创业者、战略分析人员或开发者关系人员；
- 维护开源项目、需要理解社区反馈的项目维护者。

每名参与者只使用 `P01`—`P10` 的编号。姓名、邮箱、GitHub 用户名和联系方式不进入
仓库，也不写入观察记录。

## 3. 统一任务

参与者使用部署好的 OpenScout，对公开 GitHub 产品 `langgenius/dify`、
`infiniflow/ragflow` 和 `labring/FastGPT` 完成以下任务：

> 你正在为一个需要选择开源 AI 应用平台的团队做快速初筛。请在 OpenScout 中找出：
> 1）一个最近版本或文档支持的能力事实；2）一个来自 Issue 或评论的社区信号；
> 3）两个产品之间一个有证据支持的差异。最后导出一份报告，并用不超过三句话给出
> 你的下一步建议。每个事实或统计都要能打开对应的 GitHub 证据。

任务不要求参与者得到预设答案。主持人只提供本协议中的中立提示，不解释哪个按钮、
哪个产品或哪条证据是“正确”的。

## 4. 成功标准（招募前锁定）

计时上限为 900 秒。一次任务只有在参与者完成三项证据化发现、给出三句话以内建议、
并成功导出一份报告时才记为 `completed=true`；超时、主动放弃或产品阻塞均记为 false，
不得替换失败场次。

预注册指标和继续/迭代/停止规则如下：

| 指标 | 计算方式 | 预设目标 |
| --- | --- | --- |
| 完成率 | `completed=true` 的人数 / 总人数 | ≥ 0.70 |
| 完成时间中位数 | 已完成参与者的 `seconds` 中位数 | ≤ 720 秒 |
| 平均证据点击数 | `evidence_clicks` 的算术平均 | ≥ 2 |
| 报告导出率 | `report_exported=true` 的人数 / 总人数 | ≥ 0.60 |
| 再次使用意愿 | `would_reuse=yes` 的人数 / 总人数 | ≥ 0.60 |

- 继续：完成率和再次使用意愿达到目标，且五项指标中至少四项达到目标。
- 迭代：完成率在 0.50—0.69，或阻塞失败集中影响至少两名参与者，但没有隐私或
  数据安全问题；只修复影响核心任务的前三项问题，再运行对应自动化回归。
- 停止：完成率低于 0.50，或出现未授权凭据收集、跨用户数据泄露等安全问题。

这些阈值只用于本次探索性任务决策，不构成产品质量门槛或市场成功承诺。

## 5. 主持流程与中立话术

1. 说明：“我们在测试产品，不是在测试你。请按你平时做研究的方式完成任务；如果
   不确定，可以继续尝试，但我不会告诉你答案。”
2. 读取统一任务文本，开始 15 分钟计时；主持人只记录行为和阻塞，不引导路径。
3. 参与者认为完成时停止计时；如果达到 900 秒，说明超时并记录未完成。
4. 询问：“你愿意在类似任务中再次使用这个工具吗？”只记录 `yes`、`no` 或
   `unsure`，不追问以引导正面回答。
5. 结束并说明可撤回本次记录；主持人将自由描述改写为脱敏短句后再保存。

允许的中立提示只有：“请继续按照任务要求完成即可。”和“如果页面没有响应，
请告诉我，我会记录为产品问题。”不得提示查询词、过滤器、证据位置或正确答案。

## 6. 数据、隐私与安全

- 不收集 GitHub token、密码、OAuth 授权、Cookie 或任何私有仓库凭据。
- 只使用公开 GitHub 仓库和公开链接；参与者不得在输入框粘贴秘密或个人数据。
- 只记录编号、角色类别、任务指标、阻塞类别和已经脱敏的观察笔记。
- 观察笔记删除姓名、邮箱、用户名、联系方式、设备标识、私人仓库名和自由文本中的
  凭据；无法确认是否安全时整句删除。
- 参与者可跳过问题、停止任务或要求删除本次观察记录，不影响其参与资格。
- 仓库只保存汇总后的匿名数据，不保存录音、屏幕录像或可识别的原始聊天记录。

## 7. 协议变更

成功标准、计时上限、统一任务和字段在试运行前锁定。任何变更必须记录日期、版本、
原因和影响；试运行之后不得为了提高指标而修改成功标准。
