# 用户同意与脱敏说明

## 参与者可读说明

本次活动用于评估 OpenScout 是否能帮助完成一次公开 GitHub 产品研究。活动约 15 分钟，
你可以随时停止、跳过问题或要求删除本次观察记录。我们测试的是产品，不评价你的能力。

我们只会记录一个匿名编号、角色类别、任务是否完成、用时、证据点击数、是否导出报告、
再次使用意愿、阻塞类别和脱敏观察笔记。我们不会收集姓名、邮箱、GitHub token、密码、
OAuth 授权、Cookie、私有仓库凭据、录音或屏幕录像。任务只使用公开 GitHub 仓库。

匿名汇总结果可能写入 OpenScout 仓库，用于决定继续、迭代或停止产品工作。参与完全自愿，
同意不会影响你使用其他产品或服务。

同意参加：`是 / 否`  
参与者编号：`P__`  
日期：`YYYY-MM-DD`

## 主持人脱敏规则

保存前逐句检查观察笔记：

1. 用 `P01`—`P10` 替换所有姓名、邮箱、GitHub 用户名和联系方式；
2. 删除 token、密码、Cookie、授权码、内部 URL、私有仓库名和个人数据；
3. 将具体设备、公司、团队或地理信息改写为必要的角色类别，无法安全概括时删除；
4. 只保留能解释任务阻塞或产品行为的最小事实；
5. `observations.csv` 的 `notes_redacted` 必须是脱敏短句，不粘贴原始对话。

## 可撤回处理

参与者在研究分析完成前提出撤回时，主持人使用编号定位并删除该行；不得通过姓名、
邮箱或其他新字段重新关联参与者。已发布的仅汇总结论不再恢复个体记录。
